Decision log

2026-10-26 · Pluggable template / model registries; submit only on an idle queue; never cancel others' jobs; console port 8790.

2026-10-27 · Production pipeline as YAML workflows; casting with your own photos; ComfyUI explored only through the orchestrator; downloads / node installs need approval.

2026-11-07 · General agent: the LLM proposes, the orchestrator executes generic tools too; approvals per action, "always allow", bypass.

2026-11-21 · Character LoRAs make stills; H3 LoRAs (camera, motion, style, adult) via FreeVideo's LoRA node; each LoRA download approved.

2026-11-21 · Identity: the face is decided at H3's native size; one reference sheet; keyframes on the two-pass path.

2026-11-21 · One generation renders ~5–10 s: longer content is split into shots and assembled (max_clip_seconds).

2026-11-21 · Novels: faithful adaptation; whole novel → series; cast and style decided once; one episode at a time; per-episode review level and auto shooting are settings.

2026-11-21 · Camera style: you name it, or the direction stage proposes options to choose from.

2026-11-21 · The agent hands over the original text unchanged; no agent step limit; no LLM output cap by default.
