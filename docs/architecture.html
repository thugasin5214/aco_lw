9. Novel → series

A whole book never goes into one LLM call: chapters splits it in code (第X章 / 第X回 / 卷X / Chapter N, or by length), notes reads one chapter per call, and plan groups chapters into episodes of about episode_minutes. Cast and style are decided once; then series_spawn creates only episode 1, and handoff creates the next episode (with previously-on synopses) when the previous one has finished shooting. episode_review (final / storyboard / all) and auto_shoot set how much of each episode waits for you.

A running skill stage cannot be queued again (any key on a skill stage means main); the refusal says how long it has run — long adaptations take 10–20 minutes. LLM replies have no output cap by default (llm_max_tokens = 0): thinking models spend thousands of tokens before answering.
